# Quy tắc đặt tên file đề thi

- Đặt tên file theo nội dung hoặc tiêu đề đề thi, dùng chữ thường không dấu và dấu gạch ngang.
- Mẫu ưu tiên: `<nam>-<ten-de-ngan-gon>.json`.
- Không đưa tên website hoặc nền tảng nguồn vào tên file (ví dụ: không dùng `hochanh`).
- Nếu hai tên bị trùng trong cùng thư mục, thêm hậu tố số `-2`, `-3`, ...
- Thư mục ảnh của đề phải dùng cùng tên stem với file JSON và mọi đường dẫn ảnh trong JSON phải được cập nhật tương ứng.
